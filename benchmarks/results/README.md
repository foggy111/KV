# 基准测试原始输出

这里只放 `scripts/bench.sh` 实际打出来的文本。不要手改数字，也不要把别的机器上的结果抄进来冒充。

没有 `bench-*.txt` 时，QPS、P99、CPU、错误率都是待测。

每个结果文件的文件头记录：

- 采集时间和 git 版本
- 机器名、`uname`、操作系统、是不是 WSL、CPU 型号、在线核数
- 编译器、CMake 构建类型、`src/main.cpp` 的完整编译命令
- 服务器参数（压测时带 `--quiet`）
- 负载：连接数、窗口、键数量、值长度、命令比例、预热和正式时长、重复次数
- 采样方法：`kv_bench` 对每条请求的往返时间做 nearest-rank P99，并用 `/proc/<pid>/stat` 的 utime+stime 算进程 CPU

答辩环境是 WSL2 Ubuntu 22.04。如果文件头里的系统不是它，那些数字只代表文件头写明的那台机器。答辩 PPT 上仍写待测，直到在答辩机重跑本脚本。
